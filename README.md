# 内言英語化プロジェクト

随想からテーマ別にまとめた一文の格言と、その CEFR B2 相当の英訳を声に出して練習する PWA です。

## 練習

- ランダム: 格言を順不同で連続再生
- トピック別: 選んだテーマの格言を連続再生
- 日本語を読んで英語を思い出し、英文の表示・読み上げで確認
- 録音は利用者の端末の IndexedDB に保存し、外部へ送信しません
- Service Worker によるオフライン利用

英語の読み上げはブラウザーの Speech Synthesis 機能を使います。利用可能な音声や発音は端末とブラウザーによって異なります。

## 公開範囲

このサイトには選定した格言と英訳だけを含めています。元の画像とOCR全文は含めていません。

## 開発

静的ファイルを HTTPS で配信すると、PWA と Service Worker を利用できます。GitHub Pages へは `main` ブランチへの push でデプロイします。
