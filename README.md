# 内言英語化プロジェクト

随想の画像から OCR で読み取った日本語の一文と、その CEFR B2 相当の英訳を声に出して練習する PWA です。日本語は原画像の文言をそのまま掲載し、各文に ZIP 内の画像ファイル名順で出典番号を表示します。

## 練習

- ランダム: 画像から読み取った一文を順不同で連続再生
- トピック別: 選んだテーマの一文を連続再生
- 英訳を最初から表示し、その直下の日本語原文と音声で確認
- 英文の内容語を赤字で表示
- 録音は利用者の端末の IndexedDB に保存し、外部へ送信しません
- Service Worker によるオフライン利用

英語の音声は Gemini API の `gemini-3.8-flash-tts`（低い男性声の Algieba）で事前に生成した MP3 を再生します。API キーは生成時の環境変数 `GEMINI_API_KEY` からのみ読み込み、PWA には含めません。`node scripts/generate-audio.mjs` で `data.js` の英文から音声を再生成できます（`ffmpeg` と `ffprobe` が必要）。

## 公開範囲

出典番号は `出典画像 n / 600` の形式です。n は ZIP 内に含まれる画像ファイルをファイル名順に並べたときの番号で、原資料に印刷されたページ番号ではありません。

このサイトには選定した画像内の文言と英訳だけを含めています。元の画像と OCR 全文は含めていません。

## 開発

静的ファイルを HTTPS で配信すると、PWA と Service Worker を利用できます。GitHub Pages へは `main` ブランチへの push でデプロイします。
